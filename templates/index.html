使用说明

  1. 首次使用需初始化板块数据: python main.py --init-boards
  2. 在 config.py 中填入你的 Tushare Token（注册: tushare.pro）
  3. 点击日期选择器可查看任意历史日期的竞价数据
  4. 已有本地数据的日期直接加载，未采集的日期自动从Tushare采集
  5. 交易日 9:25 集合竞价结束后数据最完整
  6. 历史数据自动保存到 data/board_summary/ 目录
  7. 若同时存在 data/concept_board_stock_map.json（概念）与 data/board_stock_map.json（行业），列表上方会出现「概念板块 / 行业板块」切换；采集时会额外写入带后缀的汇总 CSV
